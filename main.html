About the Project

This project captures real-time acceleration signals from a mobile phone using its built-in accelerometer. The X, Y, and Z axis signals are displayed in the time domain and analyzed using Fast Fourier Transform (FFT) to identify their frequency components.

Main Features

  • Real-time mobile accelerometer data
  • X, Y and Z axis signals
  • Combined acceleration signal
  • Estimated speed
  • Direction/orientation
  • Time-domain waveform
  • Frequency-domain FFT spectrum
  • Real-time signal analysis
  • Data recording and CSV export

Experiment Objective

To acquire an acceleration signal from a mobile phone, study its time-domain waveform, and use Fourier Transform to analyze the frequency components present in the signal.
